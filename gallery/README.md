# Gallery

Svelte app embedded in the MCP host (Claude Desktop, CoWork, …) as an MCP
Apps iframe. Built with Vite; assets are served by the Woof HTTP server at
`/gallery-static/`.

```
npm run dev           # local dev server
npm run build         # production build → ../src/woof/gallery/dist
npm test              # vitest
npm run test:coverage # vitest + v8 coverage report → coverage/index.html
npm run lint          # eslint
```

Architecture (smart root / dumb children, `lib/` layering), testing
conventions, and localization/theming design rationale live in the Woof LLD,
[§4.3 Gallery frontend](../doc/design/woof_LLD.md).

## Testing

Tests are colocated with source: `foo.js` → `foo.test.js`. See
`IndexingProgress.test.js` for the component-test patterns (per-test `fetch`
mock, `waitFor` for async, the MCP SDK passed in as a plain prop object).

`npm run test:coverage` runs the suite under the V8 provider and writes a
per-file table to the terminal plus an HTML report at `coverage/index.html`
(gitignored).

## Localization

UI strings are localized with [Paraglide JS](https://inlang.com/m/gerre34r).
Supported locales: `en` (base), `en-GB`, `fr`, `de`, `es`, `zh` (Simplified),
`ja`.

- **Source of truth:** `messages/{locale}.json` (inlang message format).
  `en.json` is canonical; every other locale must define the same keys — the
  `messages.test.js` completeness test enforces this.
- **Never edit `src/paraglide/`:** it is generated by the Vite plugin on every
  dev/build/test run and is gitignored.

**To add a locale:** add its tag to `locales` in `project.inlang/settings.json`,
drop a `messages/<tag>.json` with the full key set, and rebuild.
